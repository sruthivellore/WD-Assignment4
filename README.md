# 📊 Statistics App

This is a Django-based web application I created as part of a **Web Development class assignment**.  
It allows users to enter or upload a list of numbers and get detailed statistical insights — all neatly presented in a user-friendly layout.

---

## 📈 What It Does

- Accepts numbers via text input or file upload
- Validates and parses user input
- Calculates common statistics:
  - ✅ Sum
  - ✅ Mean (Average)
  - ✅ Median
  - ✅ Mode
  - ✅ Range
- Detects:
  - ✅ Prime numbers
  - ✅ Armstrong numbers
- Displays results in styled, responsive cards
- Highlights invalid inputs with clear messages

## 🛠 Tech Stack

- **Backend**: Django (Python)
- **Frontend**: HTML + CSS (no frameworks)
- **Templating**: Django Templates
- **Styling**: Custom CSS with warm, earthy tones

## ▶️ How to Run It Locally

Here’s a step-by-step guide to running the project on your local machine:

1. Clone the repository

    ```bash
    git clone https://github.com/sruthivellore/WD-Assignment4.git
    cd WD-Assignment4
    ```

2. Set up a virtual environment

    ```bash
    python -m venv venv
    ```

3. Activate the virtual environment

    ```bash
    venv\Scripts\activate
    ```

4. Install dependencies

    Install Django:

    ```bash
    pip install django
    ```


5. Start the development server

    ```bash
    python manage.py runserver
    ```

6. Open your browser and go to

    ```
    http://127.0.0.1:8000/
    ```
